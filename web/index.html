badrsi.

A language model that reads its own neurons, rewrites them, and keeps going until an unedited copy of itself agrees that it changed.

Qwen3 4B Instruct, 36 layers of 9,728 MLP neurons, in 4 bits on WebGPU. Each edit changes the mind that makes the next edit.

How it works
  1. Every neuron writes one direction. Neuron i of a layer reaches the rest of the model only through one column of that layer's output matrix. Scale the column and the neuron speaks louder or softer. Add it to every token and the neuron's idea comes up everywhere.
  2. The model holds the knife. It searches an atlas of what each neuron fires on, finds the neurons that write the words a trait would use, and edits them. The edit takes effect on its very next token, so it keeps thinking with the mind it just changed.
  3. A witness keeps it honest. A small model calls almost any edit a success. So the original, unedited weights read three answers on unrelated topics and judge from their own logits whether the trait shows.
